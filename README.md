# 曝光灯管寿命与辐照准入台（古法蓝晒底片整理室）

运行：

```bash
npm start
```

访问 `http://localhost:3040`。数据保存在 `data/exposure-lamp-console.json`。

## 三个业务模块

| 模块 | 职责 |
| --- | --- |
| 入口 `modules/intake.js` | 登记曝光单（计划时长、最低辐照），只建档排队，不触碰灯管 |
| 判定 `modules/admission.js` | 辐照准入、完成曝光、更正重算、换管复测 |
| 存档 `modules/archive.js` | 已完成 / 已拒绝单只读留档、冻结版本链、灯管履历台账 |

共享规则在 `modules/domain.js`，存储与写串行化在 `store.js`，页面在 `ui.js`。

## 业务规则

- **未完成不得再分配**：同一灯管有进行中曝光时，新单判定拒绝（占用状态由进行中曝光单派生，刷新后列表与履历一致）。
- **整单拒绝且不占灯管**：累计达到 **800 小时**、**校准过期**或**开灯实测辐照低于曝光单最低要求**（含灯管待复测）时，拒绝只写只读判定记录，不占用灯管。
- **曝光完成**：实际分钟数折算小时累计到灯管；达到 800 小时即寿限，需换管复测。
- **换管复测**：换管后第一次读数达标，须由**另一人**在**间隔 15 分钟以上**进行第二次复测且再次达标，才放行灯管，并把**累计时长归零**。
- **更正重算**：更正灯管、辐照或开灯时刻会使已放行曝光失效；旧版本冻结为「已失效」只读，按新值重新过准入；新值不达标则驳回更正、原放行保持有效。
